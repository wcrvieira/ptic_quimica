# ptic_quimica
Repositório dos materiais de Projetos de Tecnologia da Informação e Comunicação da Química.

Esta lista de exercícios, disponível em https://github.com/wcrvieira/ptic_quimica, aborda o uso de funções simples como soma e somase, além de operações matemáticas como divisão, soma, etc.

Acesse o link https://github.com/wcrvieira/ptic_quimica, baixe a planilha SigTransp.xlsx, trabalhada nas últimas aulas e, preencha as colunas que estão em amarelo. Há alguns exemplos disponíveis na planilha para auxiliar na construção das atividades.

Atividades:
1 - Coluna C - Calcular os dias entre a data de entrega e a data do pedido;

2 - Coluna F - Separar as siglas dos estados, conforme feito em aulas;

3 - Coluna H - Calcular o tempo em horas das viagens realizadas;

4 - Coluna I - Não precisa mexer. Calculando a coluna H, já aparece na coluna I, por extenso;

5 - Célula B22 - Calcular o valor dos fretes, quando selecionamos os destinos;

6 - Célula E22 - Calcular o valor dos fretes, quando selecionamos o motorista;

7 - Célula E26 - Realizar a média dos dias de entrega;

8 - Célula E30 - Calcular a média, quando selecionamos o estado.

Após preencher as colunas, favor adicionar a planilha atualizada, nesta tarefa, até às 20h00 do próximo dia 29/05.
